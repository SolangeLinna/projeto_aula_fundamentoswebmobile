# Dossiê de Arquitetura — Cronograma da Prosperidade

- Arquivos e Execução:
-- Organização Mínima: Quais tipos de arquivos são estritamente obrigatórios para o seu site existir e qual é a responsabilidade exata de cada um deles na pasta do projeto?
No projeto Cronograma da Prosperidade, o arquivo necessário para o site exista é o "index.html", afinal, ele é o primeiro a ser buscado pelo navegador, e tem a estrutura semântica da página, com cabeçalho, navegação, área principal e rodapé. O "estilo.css" é essencial para a identidade visual do site, ele define cores, tipografia, espaçamentos, botões, cabeçalho, rodapé entre ourtos. Os arquivos 'calendario.html" e "registro.html" são adirecionados pelos links de navegação, e precisam possuem o erro 404 pela fadiga da aluna. Este README.md serve para explicar e documento o projeto e as decisões técnicas
